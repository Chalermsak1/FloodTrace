# ระเบียบวิธีการพิสูจน์ข้อเท็จจริงรายงานประชาชน (Citizen Report Verification Methodology)

> **P0-1 current verification contract:** This note supersedes contradictory claims about client-synthesized evidence below; historical audits remain unchanged. Blank, null, and whitespace assessment values persist as null. `UNVERIFIED` stays unverified; `PARTIALLY_VERIFIED` moves only to `UNDER_VERIFICATION`. `VERIFIED_OBSERVATION` requires non-empty observed evidence and a permitted method. `OFFICIAL_CONFIRMED` additionally requires an official source citation. Invalid legacy records display `LEGACY_UNVALIDATED` and cannot establish verified-public eligibility. P0-2 owns the public publication filter; P0-3 owns media delivery; P0-5 owns authentication and SSE.
**ระบบ:** FloodTrace Verification Framework  
**มาตรฐานทางวิชาการ:** Mandatory 6-Dimension Structured Assessment  
**วันที่ประกาศ:** 2026-10-02  

---

## 1. วัตถุประสงค์ (Purpose)

เพื่อป้องกันการเข้าใจผิด การบิดเบือนข้อเท็จจริง และการสร้างความตื่นตระหนกในสังคม ระบบ FloodTrace กำหนดให้การพิสูจน์ข้อเท็จจริงจากรายงานของประชาชนต้องแยกความแตกต่างระหว่าง **"ข้อกล่าวอ้าง"** กับ **"ข้อเท็จจริงเชิงประจักษ์"** อย่างเด็ดขาด

```
รายงานจากประชาชน (Claim/Observation) ≠ ผลการตรวจพิสูจน์ทางวิทยาศาสตร์ (Scientific Fact)
```

---

## 2. กรอบการประเมิน 6 มิติ (The 6-Dimension Assessment Framework)

ในการบันทึกการพิสูจน์ข้อเท็จจริง (`POST /api/v1/admin/reports/{id}/verify`) ผู้ตรวจสอบจะต้องกรอกข้อมูลให้ครบถ้วนทั้ง 6 มิติ:

```
┌────────────────────────────────────────────────────────┐
│ 1. WHAT WAS REPORTED (สิ่งที่ประชาชนรายงาน)             │
│    - คำให้การดั้งเดิม ข้อสังเกต วันเวลา และพิกัดของผู้แจ้ง │
├────────────────────────────────────────────────────────┤
│ 2. WHAT WAS OBSERVED (สิ่งที่ประจักษ์จากพยานหลักฐาน)     │
│    - สิ่งที่ผู้ตรวจสอบสามารถยืนยันได้โดยตรงจากภาพถ่าย   │
│      หรือการตรวจพื้นที่ (เช่น พบปลาตาย 4 ตัวจริง)       │
├────────────────────────────────────────────────────────┤
│ 3. WHAT THE SYSTEM SHOWS (ข้อมูลระบบโทรมาตรแสดงอะไร)    │
│    - ค่าระดับน้ำและฝนจากสถานีทางการในบริเวณใกล้เคียง    │
├────────────────────────────────────────────────────────┤
│ 4. WHAT THE MODEL SUGGESTS (แบบจำลองแนวโน้มแสดงอะไร)   │
│    - ผลการคำนวณทางชลศาสตร์และแนวทางการแพร่กระจาย       │
├────────────────────────────────────────────────────────┤
│ 5. WHAT IS UNKNOWN (สิ่งที่ยังไม่ทราบแน่ชัด)            │
│    - ข้อเท็จจริงที่ยังไม่สามารถสรุปได้ในปัจจุบัน        │
│      (เช่น ยังไม่ทราบชนิดสารเคมีเนื่องจากรอผลตรวจแล็บ)   │
├────────────────────────────────────────────────────────┤
│ 6. WHAT SHOULD BE VERIFIED (ขั้นตอนการตรวจสอบถัดไป)      │
│    - มาตรการหรือการทดสอบที่ต้องดำเนินการต่อไป            │
│      (เช่น ส่งเจ้าหน้าที่เก็บตัวอย่างน้ำตรวจค่า DO/BOD)  │
└────────────────────────────────────────────────────────┘
```

## 3. ระดับสถานะการพิสูจน์ (Verification Statuses)

ระบบแบ่งระดับการพิสูจน์ข้อเท็จจริงออกเป็น 4 ระดับ:

1. **`UNVERIFIED` (ยังไม่ได้รับการพิสูจน์):**
   - สถานะเริ่มต้นของทุกรายงานที่ส่งเข้ามา
   - ยังไม่มีเจ้าหน้าที่ตรวจสอบพยานหลักฐาน
2. **`PARTIALLY_VERIFIED` (ยืนยันได้บางส่วน):**
   - พยานหลักฐานยืนยันได้เฉพาะบางข้อเท็จจริง เช่น มีน้ำท่วมขังจริง แต่ยังไม่ปรากฏกลิ่นสารเคมีตามที่อ้าง
3. **`VERIFIED_OBSERVATION` (ยืนยันข้อสังเกตแล้ว):**
   - ข้อสังเกตของประชาชนสอดคล้องกับพยานหลักฐานประจักษ์และข้อมูลโทรมาตร
   - *หมายเหตุ: การยืนยันนี้หมายถึง "ยืนยันว่าเกิดสภาพความผิดปกตินั้นจริง" มิใช่การชี้ว่ามีสารพิษอันตราย หรือโรงงานใดเป็นผู้ปล่อย*
4. **`OFFICIAL_CONFIRMED` (ได้รับการยืนยันอย่างเป็นทางการ):**
   - **กฎเหล็กที่สำคัญที่สุด:** สถานะนี้ **ไม่สามารถ** กำหนดขึ้นเองโดยการตรวจภาพถ่ายทั่วไปได้
   - **ต้องมีหลักฐานเอกสารราชการหรือผลตรวจห้องปฏิบัติการ:** เช่น หนังสือราชการจากกรมควบคุมมลพิษ สำนักงานสิ่งแวดล้อมภาค หรือผลตรวจน้ำรับรองโดยนักวิทยาศาสตร์

## 4. วิธีการตรวจสอบ (Verification Methods)

- `CROSS_CHECKED_SYSTEM_DATA`: เปรียบเทียบกับข้อมูลโทรมาตรวัดน้ำและฝนของ สสน. และ กรมชลประทาน
- `VISUAL_REVIEW`: ตรวจสอบความถูกต้องและสภาพแวดล้อมจากภาพถ่ายและวิดีโอ
- `FIELD_VERIFICATION`: เจ้าหน้าที่ลงตรวจประเมินพื้นที่จริง
- `MULTIPLE_REPORTS`: มีรายงานที่มีลักษณะข้อสังเกตสอดคล้องกันหลายจุดในรัศมีใกล้เคียง
- `OFFICIAL_SOURCE`: ได้รับข้อมูลหรือหนังสือประสานงานอย่างเป็นทางการจากหน่วยงานรัฐ
- `OTHER`: วิธีการตรวจสอบอื่นๆ ที่มีการระบุเหตุผลชัดเจน
