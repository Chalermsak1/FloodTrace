# เอกสารแจกแจงแหล่งข้อมูลภายนอกและสิทธิการเข้าถึง (DATA SOURCES)
**ขอบเขตพื้นที่:** จังหวัดปราจีนบุรี ประเทศไทย  
**สถานะการตรวจสอบ:** ร่างฉบับตรวจสอบเพื่อการใช้งานจริง (AUDIT READY)  
**วันที่ตรวจสอบล่าสุด:** 2026-10-02  

---

> [!IMPORTANT]
> ### กฎเหล็กด้านสิทธิการเข้าถึงข้อมูลเพื่อใช้งานจริง (Production Fail-Closed Mandate)
> 1. ข้อมูลทั้งหมดจากภายนอกที่จะนำเข้าสู่กระบวนการแสดงผลข้อเท็จจริงในระดับใช้งานจริง (Production) จะต้องผ่านช่องทางที่ได้รับสิทธิอนุญาตเฉพาะโครงการอย่างเป็นลายลักษณ์อักษรเท่านั้น (เช่น บันทึกข้อตกลงความร่วมมือ MOU หรือ API Key ประจำโครงการ)
> 2. **ข้อมูลสาธารณะ $\neq$ สิทธิการใช้งานเฉพาะ:** การที่ข้อมูลเปิดให้ดาวน์โหลดบนเว็บไซต์ราชการ (เช่น `data.go.th` หรือ TMD Open API) ไม่ถือว่าได้รับสิทธิการเชื่อมต่อโดยตรงในระบบระดับ Production
> 3. หากแหล่งข้อมูลใดยังไม่มีสิทธิการเข้าถึงเฉพาะ ระบบจะกำหนดสถานะเป็น **"ระงับการนำเข้า (BLOCKED)"** และแสดงต่อประชาชนอย่างตรงไปตรงมาว่า **"ข้อมูลส่วนนี้ยังรอการอนุญาตให้เข้าถึง"** โดยเด็ดขาดว่าจะไม่มีการสร้างข้อมูลเท็จขึ้นมาทดแทน

## รายละเอียดรายแหล่งข้อมูลทั้ง 15 แหล่ง (Detailed Source Specifications)

### 1. แพลตฟอร์มดาวเทียมน้ำท่วม GISTDA (`gistda_disaster`)
- **ชื่อแหล่งข้อมูล:** ระบบติดตามสถานการณ์น้ำท่วมจากภาพถ่ายดาวเทียม (GISTDA Disaster Monitoring Platform)
- **หน่วยงาน:** สำนักงานพัฒนาเทคโนโลยีอวกาศและภูมิสารสนเทศ (องค์การมหาชน) - สทอภ.
- **ใช้ทำอะไร:** ระบุขอบเขตพื้นที่น้ำท่วมจริงจากดาวเทียมเรดาร์ (Sentinel-1, COSMO-SkyMed) เพื่อซ้อนทับกับชั้นข้อมูลชุมชน
- **วิธีเข้าถึง:** ผ่าน REST API / WMS Service เฉพาะโครงการที่ได้รับ API Key
- **สถานะการอนุญาต:** `PRIVATE_PENDING` (อยู่ระหว่างการประสานงานขอความอนุเคราะห์)
- **ประเภทข้อมูล:** จำกัดสิทธิ์การใช้งานระดับ Production
- **สิทธิ์ในการเก็บข้อมูล:** จัดเก็บภาพเวกเตอร์ขอบเขตน้ำท่วมได้
- **สิทธิ์ในการเผยแพร่:** แสดงผลขอบเขตน้ำท่วมต่อสาธารณะได้
- **ความถี่ในการอัปเดต:** ตามรอบโคจรของดาวเทียม (1-2 ครั้งต่อวันในช่วงฤดูน้ำหลาก)
- **วันที่ตรวจสอบล่าสุด:** 2026-10-02
- **สถานะ Production:** **ระงับการนำเข้า (BLOCKED)** จนกว่าจะได้รับกุญแจเชื่อมต่ออย่างเป็นทางการ

### 2. โทรมาตรระดับน้ำและเขื่อน ThaiWater & กรมชลประทาน (`thaiwater_rid_runoff`)
- **ชื่อแหล่งข้อมูล:** คลังข้อมูลน้ำแห่งชาติ ThaiWater และระบบติดตามน้ำเขื่อน RID
- **หน่วยงาน:** สถาบันสารสนเทศทรัพยากรน้ำ (องค์การมหาชน) - สสน. และ กรมชลประทาน
- **ใช้ทำอะไร:** ติดตามระดับน้ำจริงในลำน้ำหลัก (แม่น้ำปราจีนบุรี แม่น้ำหนุมาน แม่น้ำพระปรง) และปริมาตรน้ำในเขื่อน
- **วิธีเข้าถึง:** REST API v3 / เว็บพอร์ทัลสาธารณะ
- **สถานะการอนุญาต:** `PUBLIC_ONLY` (มีเฉพาะช่องทางเปิดสาธารณะทั่วไป)
- **ประเภทข้อมูล:** ข้อมูลเปิดสาธารณะ (Open Government License Thailand)
- **สิทธิ์ในการเก็บข้อมูล:** จัดเก็บข้อมูลย้อนหลังได้
- **สิทธิ์ในการเผยแพร่:** เผยแพร่ระดับน้ำและแนวโน้มต่อสาธารณะได้
- **ความถี่ในการอัปเดต:** ตรวจวัดและส่งค่าอัตโนมัติทุก 1 ชั่วโมง
- **วันที่ตรวจสอบล่าสุด:** 2026-10-02
- **สถานะ Production:** **ระงับการนำเข้า (BLOCKED)** ตามนโยบายปิดกั้นข้อมูลสาธารณะจนกว่าจะมีข้อตกลงเฉพาะ

### 3. โทรมาตรสถานีวัดน้ำฝนอัตโนมัติ (`thaiwater_rainfall`)
- **ชื่อแหล่งข้อมูล:** เครือข่ายสถานีตรวจวัดปริมาณน้ำฝนอัตโนมัติ
- **หน่วยงาน:** สถาบันสารสนเทศทรัพยากรน้ำ (องค์การมหาชน) - สสน.
- **ใช้ทำอะไร:** ตรวจสอบปริมาณฝนสะสมเพื่อประเมินความเสี่ยงน้ำหลากเฉียบพลัน
- **วิธีเข้าถึง:** REST API v3
- **สถานะการอนุญาต:** `PUBLIC_ONLY`
- **ประเภทข้อมูล:** ข้อมูลเปิดสาธารณะ
- **สิทธิ์ในการเก็บข้อมูล:** จัดเก็บได้
- **สิทธิ์ในการเผยแพร่:** เผยแพร่ค่าฝนสะสมได้
- **ความถี่ในการอัปเดต:** ทุก 15 นาที
- **วันที่ตรวจสอบล่าสุด:** 2026-10-02
- **สถานะ Production:** **ระงับการนำเข้า (BLOCKED)**

### 4. แบบจำลองพยากรณ์อากาศเชิงตัวเลข TMD (`tmd_forecast`)
- **ชื่อแหล่งข้อมูล:** บริการพยากรณ์อากาศและปริมาณฝนเชิงตัวเลข (NWP / Open API)
- **หน่วยงาน:** กรมอุตุนิยมวิทยา กระทรวงดิจิทัลเพื่อเศรษฐกิจและสังคม
- **ใช้ทำอะไร:** คาดการณ์ปริมาณน้ำฝนล่วงหน้า 24-72 ชั่วโมงในพื้นที่ลุ่มน้ำ
- **วิธีเข้าถึง:** TMD Open API (ใช้กุญแจนักพัฒนาทั่วไป)
- **สถานะการอนุญาต:** `PUBLIC_ONLY`
- **ประเภทข้อมูล:** ข้อมูลเปิดสาธารณะ
- **สิทธิ์ในการเก็บข้อมูล:** จัดเก็บได้
- **สิทธิ์ในการเผยแพร่:** เผยแพร่ข้อมูลคาดการณ์ได้
- **ความถี่ในการอัปเดต:** วันละ 4 รอบ (00, 06, 12, 18 UTC)
- **วันที่ตรวจสอบล่าสุด:** 2026-10-02
- **สถานะ Production:** **ระงับการนำเข้า (BLOCKED)** ในระดับข้อมูลจริงภาคสนาม

### 5. โครงข่ายเส้นทางน้ำลุ่มน้ำปราจีนบุรี (`dwr_waterways`)
- **ชื่อแหล่งข้อมูล:** แผนที่เส้นกึ่งกลางลำน้ำและคลองระบายน้ำทางการ
- **หน่วยงาน:** กรมทรัพยากรน้ำ และ สำนักงานทรัพยากรน้ำแห่งชาติ (สทนช.)
- **ใช้ทำอะไร:** สร้างกราฟจำลองการเชื่อมต่อทางน้ำเพื่อวิเคราะห์ทิศทางการไหลต้นน้ำ-ปลายน้ำ
- **วิธีเข้าถึง:** ดาวน์โหลดชั้นข้อมูลภูมิสารสนเทศทางการ (GIS Shapefile)
- **สถานะการอนุญาต:** `PUBLIC_ONLY`
- **ประเภทข้อมูล:** แผนที่เปิดภาครัฐ
- **สิทธิ์ในการเก็บข้อมูล:** จัดเก็บโครงข่ายเวกเตอร์ได้
- **สิทธิ์ในการเผยแพร่:** แสดงผลเส้นทางน้ำบนแผนที่ได้
- **ความถี่ในการอัปเดต:** ตามรอบการสำรวจทางอุทกศาสตร์ (รายปีหรือเมื่อมีโครงการขุดลอก)
- **วันที่ตรวจสอบล่าสุด:** 2026-10-02
- **สถานะ Production:** **ระงับการนำเข้า (BLOCKED)** อนุญาตให้ใช้เฉพาะโมเดลกราฟจำลองเส้นทางน้ำ

### 6. แบบจำลองความสูงภูมิประเทศทางการ (`official_dem`)
- **ชื่อแหล่งข้อมูล:** แบบจำลองความสูงเชิงเลข (Digital Elevation Model 30m / LiDAR)
- **หน่วยงาน:** กรมแผนที่ทหาร และ กรมทรัพยากรน้ำ
- **ใช้ทำอะไร:** วิเคราะห์ความลาดชัน ทิศทางการไหลของน้ำบนผิวดิน และแอ่งรับน้ำ
- **วิธีเข้าถึง:** ส่งหนังสือขอความอนุเคราะห์ชั้นข้อมูลระดับความละเอียดสูง
- **สถานะการอนุญาต:** `PRIVATE_PENDING`
- **ประเภทข้อมูล:** จำกัดสิทธิ์การใช้งานในหน่วยงานความมั่นคง
- **สิทธิ์ในการเก็บข้อมูล:** จัดเก็บไฟล์ Raster ในเครื่องประมวลผลภายในเท่านั้น
- **สิทธิ์ในการเผยแพร่:** ห้ามเผยแพร่ไฟล์ความสูงดิบ ให้แสดงได้เฉพาะเวกเตอร์ทิศทางการไหล
- **ความถี่ในการอัปเดต:** ข้อมูลอ้างอิงคงที่
- **วันที่ตรวจสอบล่าสุด:** 2026-10-02
- **สถานะ Production:** **ระงับการนำเข้า (BLOCKED)**

### 7. ข้อมูลโรงงานกำจัดกากอุตสาหกรรม ลำดับที่ 101, 105, 106 (`diw_industrial_waste`)
- **ชื่อแหล่งข้อมูล:** รายชื่อโรงงานประเภทบำบัดและกำจัดกากของเสียอันตราย (ชุดข้อมูล snapshot พ.ค. 2563)
