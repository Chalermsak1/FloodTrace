# สถาปัตยกรรมและการทำงานของหน้าหลัก (RUWAIGON HOME DASHBOARD)

> **P0-1 current runtime status:** This note supersedes contradictory active-content descriptions below; historical audits remain unchanged. Home counts appear only when API supplies real counts. Priority, freshness, update time, map geometry, and announcements remain unavailable without eligible evidence. ThaiWater is the only active external API source. P0-3 owns media delivery; P0-5 owns authentication and SSE.

> **Legacy API restoration update (2026-10-05):** Home station totals, current-sample counts, source timestamps, and station-threshold counts come from provenance-validated public telemetry. Zero remains zero; missing or stale samples remain unavailable. Map preview uses the point-only Monitoring Priority model only when current verified station inputs exist. Unsupported boundary, waterways, flood polygons, and announcements remain unavailable. Dashboard summaries and map input refresh every 60 seconds. Live upstream reachability remains unverified in the local QA network.

**ขอบเขต:** Ruwaigon — ข้อมูลจังหวัดปราจีนบุรี (โครงการภายใน: FloodTrace)
**เส้นทาง URL:** `/overview` (หรือ `/`)  
**วัตถุประสงค์หลัก:** สื่อสารสถานการณ์สิ่งแวดล้อมและน้ำท่วมของจังหวัดปราจีนบุรีอย่างโปร่งใส เข้าถึงง่าย น่าเชื่อถือ อิงข้อมูลความจริงแบบพลวัต (Dynamic Data) โดยปราศจากการกุสถิติหรือสร้างความตื่นตระหนกเกินจริง

## 2. การเชื่อมต่อ API แบบไดนามิก (Zero Hardcoded Statistics)

ระบบหน้าแรกดึงข้อมูลจริงจาก Backend ผ่าน API สาธารณะ โดยไม่มีการใส่ตัวเลขจำลองหรือสถิติคงที่ในโค้ด:

| องค์ประกอบบนหน้า | API Endpoint | ฟิลด์ข้อมูลที่ใช้ | พฤติกรรมเมื่อข้อมูลเปลี่ยน |
|---|---|---|---|
| **เวลาอัปเดตระบบล่าสุด** | `GET /api/public/overview` | `system_updated_at_th` | คำนวณจาก `max(retrieved_at, created_at)` ล่าสุดในฐานข้อมูล |
| **บัตรสถานการณ์ล่าสุด** | `GET /api/public/overview` | `priority_counts.high` | สะท้อนจำนวนเซลล์ที่อยู่ในระดับเฝ้าระวังสูงตามผลแบบจำลองปัจจุบัน |
| **บัตรข้อมูลหน่วยงาน** | `GET /api/public/overview` | `total_water_stations + total_rainfall_stations` | นับรวมสถานีโทรมาตรจริงในฐานข้อมูล PostgreSQL |
| **บัตรรายงานประชาชน** | `GET /api/public/overview` | `total_citizen_reports` | นับเฉพาะรายงานที่ไม่ถูกปฏิเสธ (Non-rejected reports) |
| **บัตรพื้นที่เฝ้าระวัง** | `GET /api/public/overview` | `total_monitoring_cells` | นับจำนวน 45 Voronoi cells ครอบคลุม 7 อำเภอ |
| **แผนที่พรีวิวสถานการณ์** | `GET /api/public/monitoring-surface` | GeoJSON FeatureCollection | แสดงระดับความสำคัญ 5 ระดับ (VERY_HIGH, HIGH, MODERATE, LOW, NO_DATA) |
| **ข่าวสารและประกาศ** | `GET /api/public/official-updates` | Array ของประกาศทางการ | แสดงประกาศจริงจาก PCD, RID, GISTDA พร้อม URL ต้นทาง |

## 3. ขอบเขตการวิเคราะห์และข้อจำกัดทางภูมิศาสตร์

- **พื้นที่วิเคราะห์ที่ใช้งานจริง:** จังหวัดปราจีนบุรีเท่านั้น (ครอบคลุม 7 อำเภอ: อ.เมืองปราจีนบุรี, อ.กบินทร์บุรี, อ.ศรีมหาโพธิ, อ.บ้านสร้าง, อ.ประจันตคาม, อ.นาดี, อ.ศรีมโหสถ)
- **พื้นที่ภายนอกจังหวัด:**
  - แสดงด้วยหน้ากากสีเทาโปร่งแสง (Dark Neutral Mask)
  - กำกับความหมายว่า **"นอกพื้นที่วิเคราะห์ของ FloodTrace"**
  - ไม่แสดงพื้นผิวความเสี่ยง และไม่สื่อความหมายว่าเป็นพื้นที่ปลอดภัยหรือไม่มีมลพิษ

## 4. หลักการใช้คำและศัพท์บัญญัติเพื่อความถูกต้องตามกฎหมาย

1. **ลำดับความสำคัญในการเฝ้าระวัง (Monitoring / Verification Priority):**
   - ใช้คำว่า: "พื้นที่เฝ้าระวัง", "พื้นที่ที่ควรติดตาม", "ข้อมูลประกอบการตรวจสอบ", "รายงานข้อสังเกตจากประชาชน"
   - **ห้ามใช้คำว่า:** "พื้นที่ปนเปื้อน", "พื้นที่อันตราย", "โรงงานปล่อยสารพิษ", "ยืนยันมลพิษ" เว้นแต่จะมีผลตรวจจากห้องปฏิบัติการทางการรับรอง
2. **รายงานจากประชาชน:**
   - ระบุชัดเจนว่าเป็น "รายงานสังเกตการณ์เบื้องต้น" ยังไม่ถือเป็นผลยืนยันจากหน่วยงานราชการ
3. **การคุ้มครองข้อมูลส่วนบุคคล:**
   - พิกัดที่ปรากฏบนแผนที่ของรายงานประชาชนเป็น Generalized Coordinates (ปัดเศษความละเอียด)
   - ไม่แสดงชื่อ เบอร์โทรศัพท์ หรือภาพถ่ายดั้งเดิมที่มี EXIF Metadata

## 5. การจัดการข้อผิดพลาดและสถานะการโหลด (Fault Tolerance & Resilience)

- หาก API แผนที่ขัดข้อง: หน้าเว็บจะแสดงกล่องแจ้งเตือนของส่วนแผนที่โดยไม่ทำให้ส่วนอื่นของหน้าแรกหยุดทำงาน
- หาก API ประกาศหรือรายงานประชาชนขัดข้อง: จะแสดงข้อความ "ไม่สามารถโหลดข้อมูลล่าสุดได้ในขณะนี้" โดยไม่มีการแสดงตัวเลข 0 หรือข้อมูลเท็จ
- หน้าเว็บรองรับการแสดงผล Responsive บนหน้าจอ Desktop (1440px), Laptop (1024px), Tablet (768px), และ Mobile (375px)
