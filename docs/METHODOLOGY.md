# ระเบียบวิธีวิจัยและแบบจำลองทางวิทยาศาสตร์ (METHODOLOGY)
**ขอบเขตลุ่มน้ำ:** ลุ่มน้ำปราจีนบุรี (แม่น้ำหนุมาน แม่น้ำพระปรง แม่น้ำปราจีนบุรี และคลองสาขา)  
**สถานะการตรวจสอบ:** ร่างฉบับตรวจสอบเพื่อการใช้งานจริง (AUDIT READY)  
**วันที่ตรวจสอบล่าสุด:** 2026-10-02  

---

> [!IMPORTANT]
> ### หลักการทางวิทยาศาสตร์ที่ไม่สามารถประนีประนอมได้
> 1. **ระยะทางใกล้เคียง $\neq$ การปนเปื้อน (Proximity $\neq$ Contamination):** การที่โรงงานตั้งอยู่ใกล้แม่น้ำหรือพื้นที่น้ำท่วม ไม่ได้แปลว่ามีการปล่อยน้ำเสียหรือสารพิษลงสู่สิ่งแวดล้อม
> 2. **น้ำท่วมถึง $\neq$ การรั่วไหล (Flood Contact $\neq$ Release):** การที่น้ำท่วมล้นเข้าไปในบริเวณสถานประกอบการ มิได้พิสูจน์ว่ามีกากของเสียรั่วไหลออกสู่นอกโรงงาน
> 3. **น้ำไหลเชื่อมต่อกัน $\neq$ ความผิดทางกฎหมาย (Connectivity $\neq$ Guilt):** การจำลองว่าน้ำจากจุดหนึ่งสามารถไหลไปยังอีกจุดหนึ่งได้ ไม่สามารถนำไปชี้ความรับผิดทางแพ่งหรืออาญาได้
> 4. **ไม่มีการจัดอันดับโรงงานอันตราย (No Blacklist):** ระบบจะไม่สร้างการจัดลำดับความอันตรายหรือสร้างรายชื่อผู้ถูกกล่าวหา
> 5. **ต้องมีผลตรวจทางห้องแล็บเท่านั้น:** ข้อมูลการปนเปื้อนทางเคมีจำเป็นต้องได้รับการเก็บตัวอย่างตรวจวัดจริงทางห้องปฏิบัติการเท่านั้น หากไม่มีผลตรวจ ระบบจะแสดงสถานะเป็น **`INSUFFICIENT DATA (ข้อมูลไม่เพียงพอ)`** เสมอ

---

## 1. กรอบแนวคิด แหล่งกำเนิด $\rightarrow$ เส้นทาง $\rightarrow$ ตัวรับผลกระทบ (Source-Pathway-Receptor)

ระบบจัดโครงสร้างการวิเคราะห์ตามหลักการสากลทางวิทยาศาสตร์สิ่งแวดล้อม (S-P-R Framework):

```
┌─────────────────────────┐       ┌──────────────────────────┐       ┌────────────────────────┐
│     แหล่งกำเนิด (SOURCE)  │       │     เส้นทาง (PATHWAY)      │       │ ตัวรับผลกระทบ (RECEPTOR) │
│ โรงงานในระบบ กรอ.       │ ────> │ โครงข่ายลำน้ำหลัก          │ ────> │ ชุมชน / หมู่บ้าน         │
│ จุดที่ได้รับแจ้งเหตุ     │       │ ขอบเขตพื้นที่น้ำท่วมขัง     │       │ พื้นที่เกษตร / นาข้าว     │
│ ประวัติการตรวจประเมิน   │       │ ทิศทางการไหลบนผิวดิน     │       │ บ่อน้ำบาดาล / รพ.สต.    │
└─────────────────────────┘       └──────────────────────────┘       └────────────────────────┘
                                               │
                                               ▼
                              ┌───────────────────────────────────┐
                              │ ลำดับความสำคัญในการเฝ้าระวัง        │
                              │ (MONITORING PRIORITY)             │
                              │ จุดที่ควรส่งเจ้าหน้าที่ไปตรวจก่อน │
                              └───────────────────────────────────┘
```

- **มันทำงานอย่างไร:** ระบบเชื่อมโยงความสัมพันธ์ทางกายภาพระหว่างจุดที่ตั้งของกิจกรรม โครงข่ายทางน้ำ และพื้นที่เปราะบาง เพื่อประเมินว่าหากเกิดเหตุสุดวิสัย มวลน้ำจะเดินทางไปสู่จุดใด
- **มันไม่ได้หมายความว่าอะไร:** **มันไม่ได้แปลว่ามีการปนเปื้อนเกิดขึ้นแล้ว** แต่มันคือการคำนวณ **"ลำดับความสำคัญในการส่งทีมลงตรวจ (Monitoring Priority)"** เพื่อให้หน่วยงานราชการจัดสรรทรัพยากรได้อย่างมีประสิทธิภาพสูงสุด

---

## 2. การวิเคราะห์พื้นที่น้ำท่วม (Flood Extent Analysis)

- **มันทำงานอย่างไร:** รวบรวมข้อมูลขอบเขตน้ำท่วมจากดาวเทียมเรดาร์ของ GISTDA (เมื่อได้รับอนุญาต) และเปรียบเทียบกับระดับน้ำจริงในลำน้ำจากสถานีโทรมาตร เพื่อแสดงพื้นที่ที่มีน้ำท่วมขังบนแผนที่
- **มันไม่ได้หมายความว่าอะไร:** มันไม่ได้หมายความว่าน้ำทุกจุดที่ท่วมจะมีสารพิษปนเปื้อน และไม่ได้สะท้อนความลึกของน้ำในระดับเซนติเมตรในทุกตรอกซอกซอย เนื่องจากภาพถ่ายดาวเทียมมีข้อจำกัดด้านความละเอียดและสิ่งกีดขวางในเขตเมือง

---

## 3. การเชื่อมต่อทางน้ำ (Hydrological Connectivity)

- **มันทำงานอย่างไร:** ใช้โครงข่ายเส้นกึ่งกลางแม่น้ำทางการ (Hydrographic Network Graph) เพื่อจำลองการไหลของน้ำจากต้นน้ำลงสู่ปลายน้ำ เมื่อผู้ใช้เลือกตำแหน่งใดตำแหน่งหนึ่ง ระบบจะคำนวณย้อนทวนน้ำ (Upstream Tracing) และตามทิศทางน้ำ (Downstream Tracing)
- **มันไม่ได้หมายความว่าอะไร:** มันไม่ได้หมายความว่าน้ำเดินทางด้วยความเร็วเท่ากันตลอดเวลา และไม่ได้คิดรวมผลจากคันกั้นน้ำชั่วคราว ประตูปิดเปิดน้ำของชาวบ้าน หรือเครื่องสูบน้ำเคลื่อนที่ที่ไม่ได้บันทึกในระบบ

---

## 4. ลำดับความสำคัญในการเฝ้าระวัง (Monitoring Priority Scoring)

- **มันทำงานอย่างไร:** ระบบคำนวณคะแนนคัดกรองจาก 3 ปัจจัย:
  1. ความใกล้ชิดระหว่างสถานประกอบการกับลำน้ำที่มีระดับน้ำสูง ($Distance \le 500$ เมตร)
  2. การมีรายงานข้อสังเกตจากประชาชนในพื้นที่เดียวกันในช่วง 48 ชั่วโมง
  3. ปริมาณฝนคาดการณ์ล่วงหน้า
  หากครบทั้ง 3 ปัจจัย ระบบจะจัดระดับเป็น **`HIGH_PROXIMITY_INSPECTION_NEEDED`**
- **มันไม่ได้หมายความว่าอะไร:** **มันไม่ใช่การจัดอันดับความผิด** หรือการระบุว่าโรงงานใดเป็นตัวการ แต่เป็นสัญญาณเตือนให้ผู้ตรวจการสิ่งแวดล้อมลงพื้นที่เก็บตัวอย่างน้ำผิวดินมาตรวจวิเคราะห์

---

## 5. การสังเกตการณ์ของชุมชน (Community Observation)

- **มันทำงานอย่างไร:** เปิดให้ประชาชนรายงานสิ่งที่พบเห็นด้วยตาหรือกลิ่น เช่น น้ำเปลี่ยนสี มีกลิ่นเหม็นสารเคมี มีฟองผิดปกติ หรือปลาลอยตาย ระบบจะนำรายงานที่มีพิกัดใกล้เคียงกัน (ภายใน 1.5 กม.) และเวลาใกล้เคียงกัน (ภายใน 48 ชม.) มารวมกลุ่มเป็น **กลุ่มข้อสังเกตของชุมชน (Cluster)**
- **มันไม่ได้หมายความว่าอะไร:** รายงานจากประชาชนมีสถานะเป็น **`UNVERIFIED (ยังไม่ได้รับการยืนยัน)`** เสมอ ไม่สามารถใช้เป็นข้อกล่าวหาทางคดีได้จนกว่าจะมีผลตรวจทางวิทยาศาสตร์มารับรอง

---

## 6. แบบจำลองพยากรณ์อากาศและฝนสะสม (Atmospheric Weather Forecast)

- **มันทำงานอย่างไร:** ดึงข้อมูลพยากรณ์ปริมาณฝนสะสมล่วงหน้า 24-72 ชั่วโมงจากแบบจำลองเชิงตัวเลข ECMWF IFS 0.1° ผ่าน Open-Meteo หรือ TMD NWP เพื่อประเมินแนวโน้มปริมาณน้ำท่า
- **มันไม่ได้หมายความว่าอะไร:** ค่าที่ได้คือ **"ปริมาณฝนตกจากบรรยากาศ (มิลลิเมตร)"** มิใช่แบบจำลองการจำลองการท่วมเอ่อของตลิ่ง (Hydrodynamic River Inundation) จึงต้องนำไปพิจารณาร่วมกับระดับน้ำจริงในลำน้ำ

---

## 7. การเฝ้าระวังหลังน้ำลด (Post-Flood Environmental Monitoring)

- **มันทำงานอย่างไร:** เมื่อระดับน้ำในลำน้ำลดลงสู่ระดับปกติ ระบบจะแนะนำให้ตรวจสอบตะกอนดินและดินตะกอนก้นลำน้ำในพื้นที่ที่เคยถูกน้ำท่วมขังเป็นเวลานาน
- **มันไม่ได้หมายความว่าอะไร:** มันไม่ได้หมายความว่าดินในพื้นที่นั้นเกิดการสะสมของโลหะหนักเสมอไป แต่เป็นแนวทางปฏิบัติมาตรฐานด้านสุขอนามัยสิ่งแวดล้อม

---

## 8. ข้อจำกัดของแบบจำลองและความไม่แน่นอน (Model Limitations & Uncertainty)

| ปัจจัย | ระดับความไม่แน่นอน | คำอธิบายข้อจำกัด |
|---|---|---|
| การระเหยและการซึมลงดิน | ปานกลาง (Moderate) | แบบจำลองไม่ได้คำนวณอัตราการดูดซึมน้ำของดินแต่ละชนิดแบบละเอียด |
| ประตูระบายน้ำและเครื่องสูบน้ำ | สูง (High) | การเปิด-ปิดประตูระบายน้ำของกรมชลประทานหรือชาวบ้านอยู่นอกเหนือการควบคุมของโมเดล |
| คุณภาพน้ำทางเคมี | ไม่ทราบค่า (Unknown) | หากไม่มีการตรวจแล็บ จะไม่มีการคาดเดาความเข้มข้นของสารเคมีเด็ดขาด |
| สภาพภูมิประเทศระดับไมโคร | ปานกลาง (Moderate) | ถนน คันดิน หรือสิ่งปลูกสร้างใหม่อาจเปลี่ยนทิศทางน้ำในระดับท้องถิ่น |
